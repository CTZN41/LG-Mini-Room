## 마이룸 탭 개편 계획 · 2026-11-27

기준은 6418785와 Figma ‘화면’ 페이지의 360×780 현행 프레임 48개다. 아래 단계는 계획이며 개발 완료 표시는 각 단계의 검수가 끝날 때 붙인다. [디자인](https://www.figma.com/design/88W4maDBogKmapF1jrdj4S/?node-id=0-1) · [Dev Mode](https://www.figma.com/design/88W4maDBogKmapF1jrdj4S/?node-id=0-1&m=dev)

**진입 개편.** 신규 방문자는 디바이스 탭(Z02)의 상단 미니룸 카드 또는 하단 마이룸에서 문 열기(O01), 전환(O02), 세 장의 소개(O03~O05)를 거쳐 미니룸 계정으로 로그인한다. 반복 시연 기간에는 같은 브라우저에서도 미니룸 입구를 열 때마다 문 열기부터 시작한다. 소개를 마치거나 건너뛰면 유효한 세션이 있는 회원은 방으로 들어간다. 로그인 화면의 ‘미니룸 소개 다시 보기’에서 소개를 다시 볼 수 있다. 미니홈피 홈을 연결했다. 기존 드림룸 우선 원칙을 살려 최초 기본값은 H03, 홈 안에서 마이룸을 고르면 H01로 바뀐다. 방 카드 본문은 편집 가능한 내 방, 모서리 버튼은 전체 보기다. 카메라 복귀·친구 루틴 가져오기·기존 직접 주소는 각자 원래 작업으로 돌아간다.

**최초 진입 검증 · 2026-11-27.** Chrome 세로 터치 에뮬레이션(320×568, 360×780, 390×844)에서 상단 카드와 가운데 마이룸 탭, 소개 완료·건너뛰기·다시 보기, 가입 후 원래 방으로 돌아가기, 로그인된 재방문을 확인했다. 별도 시험 계정으로 카메라 복귀(모의 응답), TV 배치, 루틴 저장과 다른 브라우저에서의 재실행도 통과했다. 실물 휴대폰 및 LG 계정 인증은 이번 검수 범위 밖이다. Phase 2-A에서 미니홈피 미리보기만 A로 고정했다. B01·B02는 각각 기존 A·B·C 배치와 마지막으로 사용한 구조를 복원한다. 마이룸 가구 카드는 해당 가구의 루틴으로, 드림룸 수집 카드는 제품군별 인벤토리로 이어진다. 다음 2-B에서 등록 가전 목록의 특정 기기를 배치 편집까지 전달한다. [미니홈피 브라우저 검사](../tests/mini-home.cjs)

B01·B02 둘러보기의 닉네임·공간 선택, 레벨·포인트, 오른쪽 세로 탭, 방 카드와 하단 촬영·BGM 위치를 360×780 Figma 프레임에 맞췄다. BGM 목록과 닫기 동작은 미니홈피와 공유한다.

H01·H03은 360×780에서 상단 프로필, 286px 방 카드, 가전 세 행, 방명록과 하단 탭을 원본에 맞췄다. 방 제목과 제품명은 주아체, 레벨과 방문 수는 Silkscreen을 쓴다. BGM 아이콘은 홈과 개인 방에서 같은 네 막대를 사용한다. 가전 상태와 방문 수는 확인한 값만 표시한다.

개인 방 진입 시 제품 목록이나 배치가 늦게 도착하면 미니룸 로딩 화면을 표시한다. 회원의 방 메뉴에서 미니홈피로 돌아갈 때 현재 공간을 유지한다. [느린 진입과 오류 복구 검사](../tests/miniroom-entry.cjs)

2-A 검증 · Chrome 세로 터치 에뮬레이션 320×568, 360×780, 390×844에서 두 공간의 A·B·C 전환, A 미리보기 고정, 마지막 구조 복원, 가구별 루틴과 수집 제품군 열기를 확인했다. 360×780에서는 과거에 한 등록 기기가 두 방에 놓인 저장본을 사용해 원본 백업과 중복 해소도 확인했다. 신규 회원 시연, 온보딩, 회원별 저장 격리 검사도 통과했다. 실물 스마트폰 검수는 남아 있다.

미완성 화면은 제목과 이전 화면으로 돌아가는 길을 제공하고 준비 중인 기능을 표시한다. Figma 속 방문자 수, 가전 ON, 할인율, 결제·판매 성공을 실제 데이터처럼 표시하지 않는다. 각 단계는 변경한 화면과 기존 회원·배치·루틴 회귀 검사를 함께 통과한 뒤 다음으로 넘어간다.

## 충돌하는 요구와 결정이 필요한 항목

- **방 기본형과 진입점.** 인수인계의 기본 침대·현관문보다 최근 사용자가 정한 평마루·1인용 소파를 적용한다. 침대는 서랍에서 추가한다. 외출 루틴은 문 복구 없이 현관 매트 등 배치 가능한 물건에 연결하는 안을 먼저 검토한다. 제품 상세도 현재 모바일 기준인 한 번 탭을 유지한다.
- **명칭과 저장 범위.** 원문 ‘통합 루틴 도감’의 수집·통합 목적을 현재 화면명 ‘루틴 인벤토리’에 반영한다. ‘내 루틴’은 등록 기기로 실행할 항목이다. 드림룸 소장과 마이룸 등록은 독립적으로 유지한다. 보유 가전을 드림룸 소장품으로도 지급할지는 미정이다.
- **QR.** 체험 웹 진입 QR, 현장 수집 QR, 새 가전의 기기 등록 QR은 용도가 다르다. 채택된 체험 웹은 로그인·DB 없이 시작하고 배치는 앱 계정으로 옮기지 않는다. 체험 안에서 가상 재생을 제공하며 후속 링크도 현재 프로젝트로 연결한다.
- **가져오기와 공개.** 친구 마이룸 → 내 마이룸, 내 드림룸 → 내 마이룸은 허용한다. 친구 드림룸 → 내 드림룸은 불가, 친구 마이룸 → 내 드림룸은 미정이다. 드림룸 상시 공개·마이룸 공개 선택은 기획 결정이다. 마이룸 초기 공개값, 보유 모델·실시간 상태·예약 시각 노출 범위, 제품 자체 복사 여부는 구현 전 결정한다.
- **실행 조건.** GPS 반경 제한은 메모와 본문이 다르다. 권한 거절·집 밖 예약을 포함해 결정하기 전에는 실행 조건으로 고정하지 않는다. 2in1 구성, 원격제어 사전 허용, 본체 시작 필요 여부는 실제 대상 모델에서 확인한다.
- **보상·제안.** 최대 99레벨, 마이룸 1시간당 1 Exp, 드림룸 2대 0.5 Exp와 추가 1대당 0.5 Exp, 튜토리얼 화폐 300은 원문 기록이다. 드림룸 시간 단위·냉장고 같은 상시 가전의 상한·계정 통합·도감 보상 개수는 미정이다. 꾸미기 100·130·150, 세트 할인 5~10%는 가격 예시다. 친구 루틴의 미보유 가전 쿠폰은 할인율·중복 발급 정책이 필요하고 내 드림룸 경로 지급은 미정이다.
- **보류·제외.** 공동 드림룸은 2,900원 기록과 출시·권한 미정 기록이 공존한다. 공식 큐레이터 방, AI 추천, 희소 등급·거래·강화·합성은 제안이다. 배경음악은 권리 확인이 선행된다. 3D 편집기 이식, 캐릭터끼리 실시간 상호작용, 가전 캐릭터 대결, 설문 유형별 추천은 이번 개발 범위에서 제외한다.

계획 당시 대표 사진 보류 대상은 TV 87개와 냉장고 26개였다. 처리 결과는 위의 보류 검수 Phase 3~4에 기록했다. DB 외형 그룹이 다르더라도 방에서 보이는 형태와 색이 같으면 같은 도트를 쓸 수 있다. 반대로 같은 분류 안에서도 외형이 다르면 나눈다. 사진에 없는 뒷면 디테일과 판매 사양을 추정해 모델 차이로 만들지 않는다.

## 검증 근거

### 기존 제품 테스트 DB

2026-11-25 재확인. 현재 저장소 밖의 작업 산출물 `outputs/가전_도트_분석/제품_테스트.sqlite`에 9개 제품군이 이미 적재돼 있다. `products` 3,354행(서로 다른 모델명 3,263개)과 `sprite_examples` 31행(모델별 도트 표현 메모)이 있다. 원본 CSV 9개의 제품명·모델명·이미지 경로를 중복 포함 대조했고, 연결된 이미지 파일 3,354개의 SHA-256도 모두 일치했다. 이미지는 DB 외부 파일이며 내용이 다른 이미지는 3,065개다. 이 DB에는 바코드·기기 제어 권한·계정 및 사용자 루틴 테이블이 없다.

초기 카탈로그는 `data/products.sqlite`를 사용했다. 11월 25일 제품 도트 Phase 0에서 조회 원본을 이미지와 구성품이 들어 있는 `data/lg_appliances.db`로 전환했다. 드림룸에서 9개 제품군과 3,254개 모델을 검색·수집·배치할 수 있다. 기존 세탁기·가습기·로봇청소기 도트를 유지한다. 도트 Phase 1의 네 공기청정기는 기존 드림룸 C에서 제품 사진과 도형을 대조할 수 있다. 도트 Phase 2에서는 제습기 40개 모델의 외형 14종과 C룸 대표 전시를 구현하고 가습기·로봇청소기의 모델별 표시와 반응을 재검수했다. 도트 Phase 3에서 냉장고·세탁기·건조기의 대표 본체와 세트 구성을 구분했고, 미니워시 단품 9개를 실행 DB에서 제외했다. 도트 Phase 4에서 TV·무선청소기 955개 모델의 외형과 드림룸 세트별 구성 가전 선택·저장·재배치를 구현했다. 도트 Phase 5에서 전체 3,254개 모델의 렌더링과 C룸의 9개 제품군 배치·회전·선택·저장을 검수했다. 서로 다른 앞·뒤 도트 조합은 Phase 5의 286종에서 Phase 6의 290종으로 늘었다. 4A의 다음 작업은 실제 인식 공급자가 반환한 후보를 해당 모델에 매핑하는 것이다. 사용자별 방·루틴의 서버 저장은 별도 과제다.
