# 상업 시설에서 촬영할 수 있는 제품 검수

2026-11-26 · 실행 DB의 제품군과 모델명 조합 2,817개를 검수했다. 중복 판매행은 같은 모델로 묶되 각 행의 제품명을 함께 확인했다. 공식 제품명, 시리즈 용도와 설치 자료를 대조했다. 제품명이 단순히 ‘LG전자 + 모델번호’인 모델과 상업용·사업자 전용 표기가 없는 제품도 포함했다.
