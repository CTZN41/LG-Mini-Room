# LG 미니룸

가상 가전을 수집하고 배치한 뒤 발견한 루틴을 내 방에 맞춰 저장하는 모바일 웹 데모 프로젝트다. 현재 로컬 서버와 기본 화면을 준비했다. 첫 구현 단계는 예시 TV 수집·배치와 새로고침 후 복원이다.

## 로컬 실행

Node.js가 설치된 Windows PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다. 추가 패키지 설치 없이 시작할 수 있다.

```powershell
npm.cmd start
```

터미널에 표시된 [로컬 확인 화면](http://127.0.0.1:4173)을 연다. 직접 실행한 서버는 같은 터미널에서 Ctrl+C를 눌러 종료한다. 기본 포트가 이미 사용 중이면 다음과 같이 다른 포트에서 실행한다.

```powershell
$env:LG_MINI_ROOM_PORT = '4174'
npm.cmd start
```

서버는 이 컴퓨터의 루프백 주소에서 접속할 수 있다. 개발 페이지 파일은 public 폴더에 두고 server.mjs의 공개 경로 목록에 추가한다.
