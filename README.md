# LG 미니룸

## ThinQ에서 마이룸 열기

첫 방문은 ThinQ 디바이스 탭에서 시작한다. 위쪽 분홍 카드나 하단 **마이룸**을 눌러 문을 열고 소개 세 장을 보거나 건너뛴 뒤 미니룸 계정으로 로그인·회원가입하면 드림룸이 열린다. 반복 테스트 기간에는 미니룸 입구를 누를 때마다 소개 첫 화면이 열린다. 로그인한 회원은 소개를 끝내거나 건너뛰면 바로 방으로 들어간다. 미니홈피에서 **마이룸**을 누르면 등록 가전을, **드림룸**을 누르면 수집 가전을 본다. 두 미리보기에는 각각 A 롱 스튜디오가 보인다. 방에 들어가면 A 롱 스튜디오·B L자 거실·C 현관 투존 중 마지막으로 사용한 구조가 열리며 두 공간의 배치는 따로 저장된다. 방을 누르면 방 화면으로, 모서리 버튼을 누르면 전체 보기로 들어간다. 로그인 후 [미니홈피 열기](http://127.0.0.1:4173/miniroom/home?space=dream). **메뉴 → 제품 및 앱 활용 → LG 미니룸**은 드림룸으로 연결된다. 홈·디바이스·케어·메뉴 화면의 삽화는 제공된 ThinQ 캡처에서 가져왔다. 가입·로그인·방 복원은 `node tests/members.cjs`, UID 발급과 기존 계정 전환은 `node tests/auth-migration.cjs`로 확인한다.

홈에서 시작해 드림룸 TV를 수집·배치하고 마이룸에 영화 보기를 저장한 뒤 재실행하는 전체 검사는 `node tests/thinq-movie-journey.cjs http://127.0.0.1:4174`로 실행한다.

조명 한 대로 시작하려면 새 브라우저 프로필에서 **마이룸 → 조명 한 대로 체험**을 누른다. **배치 편집**에서 가전의 침실 조명과 가구의 침대를 놓는다. **배치 완료 → 침대 → 취침 모드 만들기**에서 이름을 정하고 미리 본 뒤 저장한다. 저장한 루틴은 침대와 하단 **내 루틴**에서 다시 실행할 수 있다. 두 경로의 검사는 `node tests/thinq-bedtime-journey.cjs http://127.0.0.1:4174`로 실행한다.

## 마이룸 등록 가전과 LG 카메라

**드림룸 → ＋ 가전 촬영**에서 LG 카메라를 열고, 돌아온 모델을 확인해 **인벤토리에 보관**하거나 **드림룸에 놓기**를 선택한다. 같은 모델은 한 번만 수집된다. 같은 제품을 다시 촬영해서 방에 한 대 더 놓을 수 있다. **마이룸 → 등록 가전 → ＋ 추가하기**는 기존처럼 등록 목록에만 추가한다.

카메라 공개판은 `/scan?returnTo=…`로 열리고 `lgcam=registered`와 JSON으로 인코딩된 `lgcam_item`을 돌려준다. 취소는 `lgcam=cancelled`다. 앱은 기존 개별 파라미터 주소도 읽는다. 실물 촬영과 외부 팀 모델의 인식 품질은 검증 대기다. [LG 카메라](https://lg-camera-lab.pages.dev/)

- 등록은 현재 브라우저의 마이룸 저장본에만 반영한다. 등록 후 목록으로 돌아오며 방에 놓으려면 **가전 목록 닫기 → 배치 편집 → 가전**에서 선택한다. 수집품·사진 원본·시리얼을 등록 기록에 넣지 않는다.
- 모델 코드는 공백 제거(양끝), 전각 문자 정규화, 대문자 변환 후 등록 목록과 대조한다. 같은 모델을 다시 받으면 ‘이미 등록된 가전이에요’가 표시된다. 기존 체험 기기는 계속 사용할 수 있다.
- 모델 라벨은 같은 제품 DB의 `/api/catalog/scan`에서 조회한다. 예를 들어 `RD21GSGR.AKOR`는 단품 `RD21GSGR`로 저장된다. 키트 판매 코드 `RD21GSGR-KG`나 미등록 모델을 받으면 본체 라벨을 다시 확인한다.
- 제품 원본은 `data/lg_appliances.db`의 `products`다. `GET /api/catalog/scan?code=RD21GSGR.AKOR`는 등록 가능한 경우 대표 제품 ID, 모델 코드, 제품명과 분류를 돌려준다. 대표 코드가 일치하지 않으면 같은 DB의 검증된 라벨만 조회한다.
- **카메라 앱 연결** · OCR에 목록이 필요하면 `GET /api/catalog/camera-products`를 사용한다. 카메라의 기존 `/products.json`과 같은 배열 형식이며 서버가 실행 DB에서 만든다. 판매 세트·제외 모델은 빠진다. 카메라 배포판에서 목록 요청을 이 주소로 바꾸고, DB에서 찾지 못한 제품은 외부 검색 결과만으로 등록하지 않는다. 웹에서 함께 쓰려면 카메라가 접근 가능한 HTTPS 미니룸 서버 주소가 필요하다. 현재 카메라 도메인에 두 읽기 API의 교차 출처 조회를 허용한다.
- 기존 실행 DB에 모델 코드 조회 인덱스를 적용하려면 프로젝트 루트에서 아래 명령을 실행한다. 제품·사진·회원 데이터는 수정하지 않는다.

```powershell
python -c "import sqlite3,pathlib; db=sqlite3.connect('file:data/lg_appliances.db?mode=rw',uri=True); db.executescript('BEGIN IMMEDIATE;'+pathlib.Path('scripts/index-shared-catalog.sql').read_text(encoding='utf-8')+'COMMIT;'); db.close()"
```

- 검증된 라벨 원본 스냅샷을 새로 받았을 때만 아래 가져오기를 실행한다. 위 공용 API 응답은 가져오기 입력으로 사용하지 않는다. 카메라에만 있는 제품은 이 작업으로 추가되지 않는다.

```powershell
python scripts/import-camera-catalog.py "C:/경로/products.json"
node tests/camera-catalog.cjs
```

## 제품 DB에서 수집하기

수집과 가전 배치에는 실행 DB에 있는 모델만 사용한다. 새 드림룸은 소파 하나가 있는 롱 스튜디오에서 시작한다. B·C 탭을 누르면 이전에 저장한 배치도 다시 열린다. 모델명이 없던 기본 예시 가전은 기존 저장본에서도 정리된다.

**드림룸 → 가전 수집 → 제품 DB에서 찾기**를 열면 제품군별 대표 도트 13종을 볼 수 있다. 제품군을 눌러 모델명·제품명으로 검색하고 **수집 → 방에 놓기**를 선택한다. 기존 세탁기 비교 모델 9종은 이전 수집 키를 사용한다. 가습기 14개 모델은 제품 사진 속 본체를 기준으로 시그니처·에센셜·하이드로타워의 세 형태와 색상을 반영해 7개 외형으로 표시한다. 컵·별도 받침 같은 구성품은 본체 도트에 포함하지 않는다. 같은 그림을 써도 모델별 수집과 배치는 독립적이다. 개별 외형을 검토하지 않은 모델은 제품군 대표 도트를 쓴다.

센서 3종, 조명 스위치 2종, AI 홈 허브 LG ThinQ ON AI(HMAK4W)는 각각 제품 사진과 도트를 제공한다. 허브의 기본 상품과 전문기사 설치 상품은 같은 모델의 설치 옵션으로 저장한다. 기존 실행 DB에 이 여섯 모델을 반영하려면 프로젝트 폴더에서 다음 명령을 실행한다.

```powershell
python scripts/import-ai-home.py "$env:USERPROFILE/Downloads/lg_ai_home_sensors_switches.db" data/lg_appliances.db
```

서버는 Node.js 24 내장 SQLite로 `data/lg_appliances.db`를 읽기 전용으로 연다. 새 작업 환경에서는 제공된 DB를 이 경로에 놓거나 `MINIROOM_CATALOG_DB`를 해당 파일의 절대 경로로 설정한다. DB 사본은 Git에서 제외한다. AI 홈 허브 추가 후 실행 DB는 3,148행이며, 제품군과 모델명의 조합은 13개 제품군에 걸쳐 3,079개다. 제품명·모델명·구성 모델로 검색할 수 있다. **제품 사진·구성**을 펼치면 DB에 들어 있는 상품 사진과 개별 구성 모델을 본다.

냉장고 1,004개, 세탁기 905개, 건조기 144개 모델은 DB의 외관·색상·구성 정보를 참조한다. 세트는 하나의 수집 키를 사용한다. 별도로 배치할 수 있는 구성 모델이 두 개 이상 확인되면 배치할 때 하나를 고른다. 미니워시가 딸린 본체는 아래 서랍을 포함한 한 개의 물건으로 이동·회전한다. 제품 사진·구성에서 부속 모델명을 확인할 수 있다. 기존 C룸의 기본 전시 자리에서는 M876GBC472, WA2525EGP6R, RD20WNR을 눌러 확인한다.

이전 C 전시에서 사용한 이동형 TV 27LX6TPGA와 무선청소기 A727TA는 모델명으로 찾을 수 있다. 두 TV가 들어 있는 세트는 **가전 수집 → 제품 DB에서 찾기 → TV**에서 `OLED55B5NNA + 27LX6TPGA`를 검색한다. 수집 후 **구성 가전 골라 놓기**를 누른다. 같은 방에 두 번째 구성품을 놓으려면 배치 편집의 가전 서랍에서 같은 세트를 다시 누른다.

전달받은 원본 DB로 교체할 때는 아래 명령으로 **새 실행용 사본**에 미니워시 단품 제외를 적용한 뒤 서버를 다시 시작한다. 기존에 적용된 DB에 다시 실행해도 결과는 같다.

```powershell
python -c "import pathlib,sqlite3; db=sqlite3.connect('file:data/lg_appliances.db?mode=rw',uri=True); db.executescript(pathlib.Path('data/remove-standalone-mini-wash.sql').read_text(encoding='utf-8')); db.close()"
```

**드림룸 → C 현관 투존**에서 360° AS206NGHA, 에어로타워 FS064PSJA, 에어로퍼니처 AS063PWGCR, 월핏 AS356LSAA를 비교한다. 제품을 누르면 모델 코드를 뺀 판매 제품명이 표시되고 고양이가 반응한다. 배치 편집에서 회전한 결과는 같은 C룸에 저장된다. 이전 전시 링크도 이 방으로 들어온다. 기존 개인 배치의 키·좌표·방향은 유지되고, 종전에 배치한 공청기도 해당 모델의 최신 그림을 사용하며 바닥 점유 크기는 유지한다. [DB·C룸 통합 검수](tests/catalog-purifier-c.cjs)

제습기 40개 모델은 상단 손잡이와 측면 물통 형태, 몸체와 손잡이 색으로 구분한 14개 도트를 쓴다. **드림룸 → C 현관 투존**에서 샌드 베이지 DQ203PCCA를 누르면 모델 사진이 열리고 고양이와 제품 표시등이 반응한다. 다른 모델은 **가전 수집 → 제품 DB에서 찾기 → 제습기**에서 고를 수 있다.

로봇청소기 39개 모델은 사진에 보이는 본체 형태, 앞 헤드, 색, 충전대 높이에 따라 20개 외형을 사용한다. 세트 상품은 세트 모델명으로 수집하고 방에는 주 로봇을 놓는다. 충전대가 보이는 모델은 제품을 눌러 반응시키거나 ‘청소 시간’을 미리 볼 때 충전대가 원래 자리에 남고 본체만 주행한다.

모서리에서 로봇청소기를 누르면 고양이는 충전대와 본체의 왕복 경로를 화면에서 가리지 않는 바닥 자리를 찾는다. ‘청소 시간’에도 같은 기준을 적용하며, 가려지는 소파 대신 가까운 빈 곳에서 청소를 지켜본다.

드림룸에서 가습기를 누르면 해당 모델의 토출구에서 물안개가 피어난다. 고양이는 가습기 옆으로 걸어가 제품 쪽을 향해 앉아 가만히 바라본다. 같은 가습기를 다시 눌러도 자리를 지키며, 다른 제품을 선택하거나 제품 카드를 닫으면 반응이 끝난다. 기기의 ‘동작 줄이기’ 설정에서는 물안개와 앉은 자세를 정지 화면으로 표시한다.

## 마이룸에서 직접 루틴 만들기

[마이룸](http://127.0.0.1:4173/editor?space=my)에서 **루틴 만들기**를 누른다. 체험용 계정은 먼저 **체험용 기기 사용**을 선택한다. 예를 들어 이름을 ‘잘 때 불 끄기’로 입력하고 거실 조명의 **조명 끄기**를 골라 **미리보기 → 내 루틴에 저장**을 누른다. 다음 방문에는 하단 **내 루틴**에서 이름을 한 번 눌러 가상 실행한다. 여러 기기를 쓰려면 같은 화면에서 각각의 동작을 고른다.

## 루틴 인벤토리

드림룸에서 TV·에어컨·워시타워를 수집해 배치하고 관련 루틴을 미리 본다. 두 방의 **인벤토리**에서 영화 보기·쾌적한 방·의류 관리·청소 시간의 발견 상태를 확인한다. 같은 브라우저의 다음 방문에도 발견한 항목을 열 수 있다. **다시 미리보기**는 필요한 제품이 있는 드림룸에서 재생하고, 마이룸이나 제품을 치운 방에서는 읽기 전용 예시 방을 사용한다.

**내 방에 맞추기**에서 등록 기기를 연결하고 저장하면 마이룸 하단 **내 루틴**에서 실행할 수 있다. 인벤토리에는 저장한 연결 보기 또는 다시 연결이 표시된다. 가전 수집 목록에서 제품별 역할을 볼 수 있고, 편집 서랍에는 드림룸의 현재 방 배치 수와 마이룸의 개별 기기 배치 상태가 표시된다.

드림룸에 TV를 놓으면 **영화 보기 가능**, 같은 방에 조명을 더 놓으면 **조명 밝기 30%**가 추가됐다는 단서가 뜬다. 직접 만든 루틴도 양쪽 방의 인벤토리에 표시된다. 같은 이름은 번호와 연결 동작으로 구별한다. 마이룸에서 침대를 놓고 **취침 모드 만들기 → 미리보기**를 누르면 고양이가 그 침대로 가서 이불을 덮는다. 저장하면 내 루틴·침대·인벤토리에서 다시 실행할 수 있다.

## 두 방에 가전 넣기

- **드림룸**에서 **가전 수집**을 연다. 사진을 찍거나 파일을 선택한 뒤 사진 속 제품을 직접 고른다. 예시 카탈로그에서도 바로 수집할 수 있다. **방에 놓기**를 누르면 현재 방에서 제품이 선택되어 바로 끌어 옮길 수 있다. **계속 수집**은 방금 본 제품 위치에서 카탈로그를 이어 연다. 나중에 놓으려면 **인벤토리 → 가전**에서 수집품을 누르고 방에서 위치를 확정한다. 이미 놓인 물건은 같은 목록에서 찾아 수납할 수 있다. 사진은 미리보기에만 쓰고 브라우저에는 제품 종류와 수집 경로를 저장한다.
- **마이룸**의 **등록 가전**에는 ThinQ에서 가져온 기기가 표시된다. 제품 서랍에서 같은 모델의 두 기기를 각각 이름으로 골라 놓을 수 있다. 목록을 다시 불러오면 등록 해제한 기기는 배치와 루틴 후보에서 사라진다. 현재 도트 이미지가 없는 제품은 목록에 ‘배치 미지원’으로 표시된다.
- 계정 설정 전에는 **체험용 기기 사용**을 눌러 예시 등록 목록으로 같은 흐름을 테스트할 수 있다. 체험 배치와 저장 루틴은 계정 연결 때 별도 공간에 보관된다. 소파·침대 등 일반 가구는 양쪽 방에서 쓸 수 있다.

### 사진 후보 흐름 체험하기

드림룸의 **가전 수집**에서 사진을 선택한다. 기본값인 **직접 선택**은 기존 카탈로그를 연다. **사진 후보 체험**을 **예시 · TV 한 대** 또는 **예시 · 냉장고 여러 대**로 바꾸면 선택한 시나리오의 후보가 나타난다. 원하는 후보에서 **수집 → 방에 놓기**를 누르면 편집 모드로 이어진다. 실제 사진 판독은 팀원 모델을 연결한 뒤 제공한다.

**예시 · 일치 없음**이나 **예시 · 조회 실패**로 바꾸면 재시도와 수동 선택 경로를 확인할 수 있다. 사진 원본과 파일명은 전송·저장하지 않는다. 수집 출처와 예시 후보의 확정·수정·직접 선택 여부는 이 브라우저에 기록된다.

### 내 ThinQ 목록 연결하기 (선택)

로컬 PC에서 Python 3.10 이상과 LG의 Python SDK를 사용한다. 계정의 국가 코드와 기기 목록 조회 권한이 있는 개인 액세스 토큰을 준비한다. 프로젝트 폴더의 PowerShell에서 아래 명령으로 서버를 시작한 뒤 마이룸을 연다. 토큰 입력란은 가려진다. [LG ThinQ Connect SDK 및 토큰 발급 안내](https://github.com/thinq-connect/pythinqconnect)

```powershell
python -m venv "$env:LOCALAPPDATA\MiniRoomSDK"
$env:MINIROOM_PYTHON = "$env:LOCALAPPDATA\MiniRoomSDK\Scripts\python.exe"
& $env:MINIROOM_PYTHON -m pip install thinqconnect==1.0.14
$env:THINQ_COUNTRY = 'KR'
$env:THINQ_PAT = [System.Net.NetworkCredential]::new('', (Read-Host 'ThinQ 개인 액세스 토큰' -AsSecureString)).Password
npm.cmd start
```

계정 목록은 서버를 실행한 PC의 localhost에서 조회한다. 방 안 루틴은 가상 미리보기로 실행된다. 조회 오류가 나면 마이룸의 **다시 불러오기**로 재시도한다.

## 가전 루틴 사용하기

- [드림룸](http://127.0.0.1:4173/editor?space=dream)에서 가전을 누르면 제품명과 고양이 반응을 볼 수 있다. 에어컨·공기청정기에서는 **쾌적한 방**, 워시타워·스타일러에서는 **의류 관리** 버튼으로 루틴을 연다. 미리보기로 방 안의 가전 반응을 확인하고 ‘내 방에 맞추기’를 누른다.
- [마이룸](http://127.0.0.1:4173/editor?space=my)에서는 ‘루틴 추가’ 또는 ‘다른 가전 루틴’으로 시작할 수 있다. 처음에는 ‘체험용 기기 사용’을 누른다. 원하는 기기가 방에 없으면 연결 화면에서 체험용 기기를 배치한다.
- 에어컨 냉방에는 공기청정기 자동 청정을, 워시타워 표준 세탁에는 스타일러 리프레시를 함께 연결할 수 있다. 보조 기기는 선택 항목이다. 같은 제품이 두 대면 목록 번호로 구분해 선택한다. 미리보기에서 ‘내 루틴에 저장’을 누르면 마이룸 하단에서 해당 루틴을 다시 실행할 수 있다.
- 마이룸 하단의 **루틴 추가**에서 여러 루틴을 체크하고 각 기기를 고른 뒤 **N개 루틴 저장**을 누른다. 기존 설정은 미리 채워지고, 선택한 저장본의 변경은 한 번 확인한다. TV 연결 화면에서는 **여러 루틴 설정**으로 같은 창을 연다. 방 안의 제품을 누르면 개별 루틴 미리보기를 이용할 수 있다. 체험 기기는 브라우저 안에서만 동작한다.

## MY DOT ROOM 배치 에디터

프로젝트를 실행하고 [배치 에디터](http://127.0.0.1:4173/editor)를 연다. 첫 방문은 B의 핑크 톤이다. 다음 방문에는 마지막 방과 톤, 세 방의 배치를 자동 복원한다. [루틴 체험 메뉴](http://127.0.0.1:4173/#menu)에서도 배치 에디터로 이동할 수 있다.

1. 드림룸 또는 마이룸에서 **배치 편집**을 누르고 서랍에서 카테고리를 고른다. 세로 화면에서는 ‘펼치기’를 누르거나 서랍 제목을 위로 밀어 목록을 연다. 카드를 누르면 방에 제품이 추가되고 서랍이 접힌다.
2. 방의 제품을 끌어 배치한다. 제품명 옆의 ↺·↻ 버튼으로 90°씩 회전하고 높이를 바꾼다. 소파는 ‘TV 쪽으로’를 누르면 가까운 TV를 향한다. 벽걸이는 두 벽 사이에서 전환한다. 여러 제품이 겹친 곳을 누르면 ‘겹친 제품’으로 같은 위치의 다른 제품을 고를 수 있다.
3. 두 손가락이나 ＋·− 버튼으로 확대하고 빈 곳을 끌어 둘러본다. A의 ‘벽면 확대’는 가전 진열을 보여준다. ‘전체 보기’로 돌아온다.
4. 오른쪽 위 ‘···’ 메뉴에서 이미지로 보기, PNG 저장, 배치 파일 저장·불러오기, 현재 방의 기본 배치·비우기를 사용한다. 데스크톱은 방향키로 이동하고 R·Shift+R로 오른쪽·왼쪽으로 회전한다. 벽걸이 제품과 받침대 없이 그려진 평판 TV에서만 [와 ]로 높이를 조절한다. Delete는 삭제, Ctrl+Z는 되돌리기다.

**배치 완료 → 방 안의 TV → 영화 보기** 순서로 시청을 체험한다. 고양이는 누른 TV 근처에 소파가 있으면 앉고, 소파가 멀거나 없으면 그 TV 앞에 서서 본다. 영화 보기를 누르면 TV와 연결한 조명이 반응한다. 드림룸에서는 가상으로 체험한다. 마이룸에서는 ‘체험용 기기 사용’으로 시작해 TV와 선택한 조명을 연결하고, 미리보기에서 ‘내 루틴에 저장’을 누른다. 다음 방문에는 마이룸 하단 ‘내 루틴 → 영화 보기’를 한 번 눌러 재생하고 같은 자리에서 종료한다. 기존 저장본도 자동으로 표시된다.

**TV 선택과 재연결** — 새 체험용 마이룸에는 거실 TV와 침실 TV가 등록된다. ‘루틴 연결’ 또는 ‘연결 설정’에서 ‘재생할 TV’를 고르고 미리본 뒤 저장한다. 기존 한 대짜리 마이룸은 ‘··· → 체험용 TV 관리 → 침실 TV 등록’으로 두 번째 TV를 추가할 수 있다. 저장된 TV를 등록 해제한 다음 ‘완료’를 누르면 하단 ‘내 루틴’에 ‘재연결 필요’가 표시된다. ‘TV 다시 연결 → 대체 TV → 연결하고 재생’을 누르면 기존 조명 설정을 유지하면서 TV만 바꾸고 바로 재생한다.

다운로드한 원본에서 쓰던 배치를 이어가려면 같은 Chrome 프로필에서 프로젝트의 `public/dot-room.html`을 직접 연다. 로컬 파일과 서버는 서로 다른 저장 공간을 쓴다. 로컬 파일의 ‘방 메뉴 → 배치 파일 저장’으로 JSON을 받은 뒤 서버의 ‘배치 파일 불러오기’로 옮길 수 있다. 드림룸 배치는 기존 `dotroom`, 마이룸 배치는 `lg-miniroom.dot.my`, 등록 기기와 저장 루틴은 `lg-miniroom.state`에 저장한다.

같은 Wi-Fi의 휴대폰에서 직접 열려면 서버를 실행하는 PowerShell에서 `$env:LG_MINI_ROOM_HOST = '0.0.0.0'`을 설정하고 아래 실행 명령을 사용한다. 휴대폰 브라우저에서 `http://PC의-무선-LAN-IPv4:4173/editor`를 연다. PC의 IPv4 주소는 `ipconfig`에서 확인한다.

가상 가전을 수집하고 배치한 뒤 발견한 루틴을 내 방에 맞춰 저장하는 모바일 웹 데모 프로젝트다. 휴대폰 세로 화면에서 2D 도트 방과 하단 가구 보관함을 사용한다. 가로 모드도 지원한다. 드림룸에 놓은 TV를 누르거나 예시 친구 방의 소파를 눌러 영화 보기 루틴을 발견한다.

## 로컬 실행

Node.js가 설치된 Windows PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다. 별도 패키지 설치 없이 npm.cmd start로 실행한다. 방과 가구는 브라우저의 Canvas 2D로 그린다.

```powershell
npm.cmd start
```

터미널에 표시된 [로컬 확인 화면](http://127.0.0.1:4173)을 연다. 직접 실행한 서버는 같은 터미널에서 Ctrl+C를 눌러 종료한다. 기본 포트가 이미 사용 중이면 다음과 같이 다른 포트에서 실행한다.

```powershell
$env:LG_MINI_ROOM_PORT = '4174'
npm.cmd start
```

서버는 이 컴퓨터의 루프백 주소에서 접속할 수 있다. 개발 페이지 파일은 public 폴더에 두고 server.mjs의 공개 경로 목록에 추가한다.

## 방문자용 QR 체험

`/experience`는 새로 열 때마다 소파 한 개로 시작하는 마케팅용 거실이다. `/experience/qr`에서 현장 QR을 표시한다. 기존 앱 서버에서도 두 경로를 제공한다. 행사 네트워크에서는 아래처럼 방문자 전용 서버만 열 수 있다. PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다. 처음 설치할 때는 `npm.cmd install`로 QR 생성 패키지를 준비한다.

```powershell
$env:MINIROOM_VISITOR_ONLY = '1'
$env:LG_MINI_ROOM_HOST = (Get-NetIPConfiguration | Where-Object { $_.IPv4DefaultGateway -and $_.IPv4Address } | Select-Object -First 1).IPv4Address.IPAddress
$env:LG_MINI_ROOM_PORT = '4185'
node server.mjs
```

서버에 표시된 주소의 `/experience/qr`을 PC에서 열고 같은 네트워크의 휴대폰으로 스캔한다. 방문자 전용 서버는 체험 화면과 정적 에셋만 제공한다. 계정, DB, ThinQ 키가 필요 없다. 55LX1QKNA의 검수된 제품 사진과 외형을 체험에 묶었다.

TV와 조명을 놓고 끌어서 옮긴 뒤 TV를 눌러 영화 보기를 선택한다. 일반 서버의 시연 QR은 미니룸 소개 입구 `/miniroom/start`로, 방문자 전용 서버의 QR은 `/experience`로 연결된다. 제품 상세·미리보기·종료 화면의 **미니룸 첫 화면 열기**는 같은 서버의 `/`를 연다. 일반 서버에서는 프로젝트 홈, 방문자 전용 서버에서는 체험 첫 화면이 열린다. 체험 배치는 메모리에서만 유지한다.

관찰할 때만 QR 페이지 URL 끝에 `?observe=1`을 붙인다. 체험 종료 화면에서 현재 방문의 기록을 내려받을 수 있다. `project_home_clicked`는 프로젝트 첫 화면 링크를 누른 시점에 기록한다.
