# LG 미니룸

## 가전 루틴 사용하기

- [드림룸](http://127.0.0.1:4173/editor?space=dream)의 기본 B 방에서 에어컨·공기청정기를 누르면 **쾌적한 방**, 워시타워·스타일러를 누르면 **의류 관리**가 열린다. 미리보기로 방 안의 가전 반응을 확인하고 ‘내 방에 맞추기’를 누른다.
- [마이룸](http://127.0.0.1:4173/editor?space=my)에서는 ‘루틴 추가’ 또는 ‘다른 가전 루틴’으로 시작할 수 있다. 처음에는 ‘체험용 기기 사용’을 누른다. 원하는 기기가 방에 없으면 연결 화면에서 체험용 기기를 배치한다.
- 에어컨 냉방에는 공기청정기 자동 청정을, 워시타워 표준 세탁에는 스타일러 리프레시를 함께 연결할 수 있다. 보조 기기는 선택 항목이다. 같은 제품이 두 대면 목록 번호로 구분해 선택한다. 미리보기에서 ‘내 루틴에 저장’을 누르면 마이룸 하단에서 해당 루틴을 다시 실행할 수 있다.
- 마이룸 하단의 **루틴 추가**에서 여러 루틴을 체크하고 각 기기를 고른 뒤 **N개 루틴 저장**을 누른다. 기존 설정은 미리 채워지고, 선택한 저장본의 변경은 한 번 확인한다. TV 연결 화면에서는 **여러 루틴 설정**으로 같은 창을 연다. 방 안의 제품을 누르면 개별 루틴 미리보기를 이용할 수 있다. 체험 기기는 브라우저 안에서만 동작한다.

## Phase 4 사용자 관찰

[진행 대본과 기록표](PHASE4.md)에 두 경로의 시작 주소, 참가자 과제, 독립 완주 판정 기준이 있다. 관찰 모드는 [미니룸 메뉴](http://127.0.0.1:4173/?observe=1#menu)에서 시작한다. 방 메뉴의 ‘관찰 기록 내려받기’로 현재 탭의 이벤트를 저장한다.

## MY DOT ROOM 배치 에디터

프로젝트를 실행하고 [배치 에디터](http://127.0.0.1:4173/editor)를 연다. 첫 방문은 B의 핑크 톤이다. 다음 방문에는 마지막 방과 톤, 세 방의 배치를 자동 복원한다. [루틴 체험 메뉴](http://127.0.0.1:4173/#menu)에서도 배치 에디터로 이동할 수 있다.

1. 드림룸 또는 마이룸에서 **배치 편집**을 누르고 서랍에서 카테고리를 고른다. 세로 화면에서는 ‘펼치기’를 누르거나 서랍 제목을 위로 밀어 목록을 연다. 카드를 누르면 방에 제품이 추가되고 서랍이 접힌다.
2. 방의 제품을 끌어 배치한다. 제품명 옆의 ↺·↻ 버튼으로 90°씩 회전하고 높이를 바꾼다. 소파는 ‘TV 쪽으로’를 누르면 가까운 TV를 향한다. 벽걸이는 두 벽 사이에서 전환한다. 여러 제품이 겹친 곳을 누르면 ‘겹친 제품’으로 같은 위치의 다른 제품을 고를 수 있다.
3. 두 손가락이나 ＋·− 버튼으로 확대하고 빈 곳을 끌어 둘러본다. A의 ‘벽면 확대’는 가전 진열을 보여준다. ‘전체 보기’로 돌아온다.
4. 오른쪽 위 ‘···’ 메뉴에서 이미지로 보기, PNG 저장, 배치 파일 저장·불러오기, 현재 방의 기본 배치·비우기를 사용한다. 데스크톱은 방향키로 이동하고 R·Shift+R로 오른쪽·왼쪽으로 회전한다. [와 ]는 높이, D는 복제, Delete는 삭제, Ctrl+Z는 되돌리기다.

**배치 완료 → 방 안의 TV → 영화 보기** 순서로 시청을 체험한다. 고양이는 누른 TV 근처에 소파가 있으면 앉고, 소파가 멀거나 없으면 그 TV 앞에 서서 본다. 영화 보기를 누르면 TV와 연결한 조명이 반응한다. 드림룸에서는 가상으로 체험한다. 마이룸에서는 ‘체험용 기기 사용’으로 시작해 TV와 선택한 조명을 연결하고, 미리보기에서 ‘내 루틴에 저장’을 누른다. 다음 방문에는 마이룸 하단 ‘내 루틴 → 영화 보기’를 한 번 눌러 재생하고 같은 자리에서 종료한다. 기존 저장본도 자동으로 표시된다.

**TV 선택과 재연결** — 새 체험용 마이룸에는 거실 TV와 침실 TV가 등록된다. ‘루틴 연결’ 또는 ‘연결 설정’에서 ‘재생할 TV’를 고르고 미리본 뒤 저장한다. 기존 한 대짜리 마이룸은 ‘··· → 체험용 TV 관리 → 침실 TV 등록’으로 두 번째 TV를 추가할 수 있다. 저장된 TV를 등록 해제한 다음 ‘완료’를 누르면 하단 ‘내 루틴’에 ‘재연결 필요’가 표시된다. ‘TV 다시 연결 → 대체 TV → 연결하고 재생’을 누르면 기존 조명 설정을 유지하면서 TV만 바꾸고 바로 재생한다.

다운로드한 원본에서 쓰던 배치를 이어가려면 같은 Chrome 프로필에서 프로젝트의 `public/dot-room.html`을 직접 연다. 로컬 파일과 서버는 서로 다른 저장 공간을 쓴다. 로컬 파일의 ‘방 메뉴 → 배치 파일 저장’으로 JSON을 받은 뒤 서버의 ‘배치 파일 불러오기’로 옮길 수 있다. 드림룸 배치는 기존 `dotroom`, 마이룸 배치는 `lg-miniroom.dot.my`, 등록 기기와 저장 루틴은 `lg-miniroom.state`에 저장한다.

같은 Wi-Fi의 휴대폰에서 직접 열려면 서버를 실행하는 PowerShell에서 `$env:LG_MINI_ROOM_HOST = '0.0.0.0'`을 설정하고 아래 실행 명령을 사용한다. 휴대폰 브라우저에서 `http://PC의-무선-LAN-IPv4:4173/editor`를 연다. PC의 IPv4 주소는 `ipconfig`에서 확인한다.

가상 가전을 수집하고 배치한 뒤 발견한 루틴을 내 방에 맞춰 저장하는 모바일 웹 데모 프로젝트다. 휴대폰 세로 화면에서 2D 도트 방과 하단 가구 보관함을 사용한다. 가로 모드도 지원한다. 드림룸에 놓은 TV를 누르거나 예시 친구 방의 소파를 눌러 영화 보기 루틴을 발견한다.

## 로컬 실행

Node.js가 설치된 Windows PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다. 별도 패키지 설치 없이 npm.cmd start로 실행한다. 방과 가구는 브라우저의 Canvas 2D로 그린다.

```powershell
npm.cmd start
```

터미널에 표시된 [로컬 확인 화면](http://127.0.0.1:4173)을 연다. 직접 실행한 서버는 같은 터미널에서 Ctrl+C를 눌러 종료한다. 기본 포트가 이미 사용 중이면 다음과 같이 다른 포트에서 실행한다.

```powershell
$env:LG_MINI_ROOM_PORT = '4174'
npm.cmd start
```

서버는 이 컴퓨터의 루프백 주소에서 접속할 수 있다. 개발 페이지 파일은 public 폴더에 두고 server.mjs의 공개 경로 목록에 추가한다.

Chrome이 설치된 PC에서 로컬 서버를 실행한 뒤, 저장소 폴더에 두 번째 터미널을 열어 아래 명령을 실행한다. Playwright는 브라우저 검증에 사용한다. 각 스크립트는 격리된 브라우저 저장 공간을 쓰며, 첫 번째 인수로 다른 로컬 서버 주소를 지정할 수 있다.

```powershell
npm.cmd install --no-save --package-lock=false playwright
node tests/friend-room.cjs
node tests/tv-interaction.cjs
node tests/tv-reconnection.cjs
node tests/batch-routines.cjs
```
